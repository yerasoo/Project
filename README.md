# 오늘의 할 일

브라우저에서 바로 쓰는 간단한 할 일 관리 웹앱입니다. 설치할 것 없이 `index.html` 파일 하나로 동작합니다.

## 기능
- 할 일 추가 (마감일, 중요도 선택 가능)
- 완료 체크와 진행률 표시
- 더블클릭으로 수정, × 버튼으로 삭제 (5초 안에 되돌리기 가능)
- 전체 / 진행 중 / 완료 보기
- 마감일 표시: 오늘, 내일, D-3, 1일 지남
- 다크 모드 자동 지원
- 목록은 브라우저(localStorage)에 저장

## 휴대폰에 앱으로 설치하기
GitHub Pages로 공개한 뒤 휴대폰에서 주소를 열고 홈 화면에 추가하면 앱처럼 쓸 수 있습니다. 설치하면 인터넷 없이도 열립니다.

- **아이폰 (Safari)**: 공유 버튼 → **홈 화면에 추가**
- **안드로이드 (Chrome)**: 오른쪽 위 ⋮ 메뉴 → **앱 설치** 또는 **홈 화면에 추가**

## 실행 방법
`index.html` 파일을 브라우저로 열면 됩니다. 오프라인 기능은 GitHub Pages처럼 `https://` 주소로 열었을 때만 동작합니다.

## 앱을 수정했을 때
`sw.js`의 `CACHE` 값(`todo-v1`)의 숫자를 올려야 휴대폰에 설치된 앱도 새 버전으로 바뀝니다.
